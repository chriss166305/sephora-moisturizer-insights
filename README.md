# Sephora-moisturizer-insights
AI-assisted customer insights pipeline analyzing Sephora moisturizer reviews with SQL, LLM classification, human evaluation, and Tableau.

## Data Source

This project uses the third-party Kaggle dataset
[Sephora Products and Skincare Reviews](https://www.kaggle.com/datasets/nadyinky/sephora-products-and-skincare-reviews).

The dataset contains historical product information from Sephora's
website and 285,412 customer skincare reviews collected through
third-party web scraping.

Downloaded: August 2026

Raw data is not redistributed in this repository.
